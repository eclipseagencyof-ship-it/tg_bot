# Анкета кандидатов Eclipse — Render 24/7

## ВАЖНО: безопасность токена

Старый токен был отправлен в переписку. **Отзовите его в @BotFather** (`/mybots` → бот → API Token → Revoke) и создайте новый.
Новый токен храните ТОЛЬКО в переменной окружения `BOT_TOKEN` на Render. Никогда не вписывайте его в bot.py, render.yaml, GitHub или сообщения.

## Что делает бот

`/start` начинает анкету: имя → 18+ → опыт → подробности опыта (если да) → смена → ожидаемая зарплата → обучение → контакт по желанию.
После заполнения посылает анкету в **личные сообщения Telegram пользователя 8327257248**, включая ссылку на кандидата, username (если есть) и номер (если кандидат им поделился).
`/cancel` сбрасывает анкету. Кандидаты младше 18 лет отсеиваются.

## Как запустить на Render (Background Worker)

1. Сначала откройте нового бота в Telegram, отправьте `/start` со своего личного аккаунта 8327257248: Telegram не разрешает боту первым писать незнакомому пользователю.
2. Создайте **приватный** репозиторий GitHub и загрузите в корень файлы этого проекта (bot.py, Dockerfile, requirements.txt, render.yaml, .gitignore). **Не загружайте `.env` или токен.**
3. Откройте https://dashboard.render.com → **New** → **Background Worker** (названия меню могут меняться) → подключите репозиторий.
4. Используйте **Docker** / Dockerfile в корне проекта. Тариф: **платный, без засыпания** (обычно Starter или выше); подтвердите актуальную цену и доступность в личном кабинете Render.
5. В **Environment** добавьте:
   - `BOT_TOKEN` — НОВЫЙ токен после отзыва старого;
   - `ADMIN_CHAT_ID` — `8327257248`.
6. Запустите **Deploy**. В Logs ожидайте информацию о polling, без ошибок с токеном.
7. Откройте бота другим аккаунтом, пройдите тестовую анкету и проверьте сообщение админу.

**Вариант через Blueprint:** `render.yaml` содержит определение Background Worker и значение ADMIN_CHAT_ID; при создании Blueprint Render запросит секрет BOT_TOKEN. Стоимость и доступность worker нужно проверить в Render.

## Почему Worker, а не бесплатный Web Service

Бот использует Telegram long polling, ему нужен непрерывно работающий процесс, а не HTTP-страница. Бесплатные Web Services могут засыпать; внешние uptime-пинги не обеспечивают круглосуточную работу. Background Worker с подходящим оплачиваемым тарифом — правильная модель для этого кода.

## Ограничения

Промежуточные ответы хранятся в оперативной памяти: если Render перезапустит процесс, незавершённую анкету придётся начать заново. **Завершённые анкеты отправляются админу сразу**, но отдельной базы и панели управления нет.
Telegram-ссылка `tg://user?id=...` помогает открыть пользователя; возможность написать ему напрямую может зависеть от настроек Telegram. Номер телефона передаётся только при добровольном согласии кандидата.
